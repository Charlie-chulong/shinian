拾念 · Shinian 1.0.0
留住每一个好想法。

【打开软件】
完整解压压缩包，双击 Shinian.exe。
请保留旁边所有 DLL、resources、locales 等文件，不能只复制 EXE。
Windows x64 免安装版，无需 Node.js、Python 或登录账号。

【三步开始】
1. 在上方输入一句灵感，按 Enter 保存。
2. 点击“我的分类”旁的 +，自定义名称和颜色。拖动卡片到任意分类。
3. 把灵感转成待办，设置截止日期和子任务；点击完成按钮，或在看板里拖到“已完成”。

【随时呼出】
拾念运行期间：Ctrl + Alt + Space 打开快捷记录。
快捷键被占用时，可在“设置 → 快捷键”更换组合。
主窗口快捷键：N 新灵感；T 新待办；Ctrl + K 搜索。
编辑器会自动保存，Ctrl + Enter 保存并关闭。

【关闭与退出】
默认关闭窗口后留在系统托盘，仍可快捷记录。
要完全退出，请右键托盘图标选择退出，或按 Ctrl + Q。
“设置 → 外观与习惯”可切换深浅主题、窗口置顶、托盘和登录电脑时启动。

【数据在哪里】
默认保存到：%APPDATA%\Shinian
“设置 → 数据与备份”可打开目录、导出 JSON、导出 Markdown、导入、恢复备份。
主数据：shinian.json
有效副本：latest-good.json
历史备份：backups 文件夹（自动快照保留 14 个日历日）。
移动软件文件夹不会同时移动或删除记录。
更换电脑时，请先导出完整 JSON，再在新电脑导入。
本机自动备份不等于异地备份，建议定期把 JSON 另存到另一块磁盘。

【一些贴心的小规则】
- 初次打开是空白工作区。可以选择载入明确标注的虚构示例。
- 删除分类会把内容移回收集箱，不会删除灵感。
- 删除内容先进入回收站，可以恢复。永久删除会再次确认。
- 完成的事项可以重新打开。
- 导入采用合并策略，已有内容保留，冲突内容保留副本。
- 截止日期用于今日关注和逾期显示；本版不提供后台定时通知。
- 未提交草稿属于缓存，请点击保存后再作为正式记录备份。
